# DSH Dot acceptance checklist

This is the acceptance checklist for the DSH DSH Dot plugin.

- [x] Persistent Dot Agent/Session with a title and durable resume
- [x] Real read-only research: filesystem and public GitHub issues API
- [x] Independent small-model risk review
- [x] User-only approval through the Dot panel
- [x] Real scoped execution with per-proposal tool allowlist
- [x] Real long-running task, DSH schedule, and local event trigger
- [ ] Connect a real Gmail/Calendar/Slack MCP server
- [ ] Exercise auto-approval with `autoApproveLowRisk: true`
- [ ] Add a second Dot for a separate workspace
